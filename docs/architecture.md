#Назначение системы
Программа предназначена для ввода вещественной матрицы заданной размерности n*m построчно, выполнения над ней операции транспонирования и вывода в консоль. Система работает в интерактивном циклическом режиме.

#Технологический стек
Язык программирования: Python 13.3
Используемые библиотеки: отсутствуют

#Компонентная структура
1. Блок управления жизненным циклом. Позволяет пользователю повторно запустить алгоритм, без перезапуска программы.
2. Блок ввода размерности. Позволяет пользователю ввести размерность. Обрабатывает ввод с целью исключения ошибок в дальнейшей работе программы. Обрабатываемые ошибки: ввод чисел меньше или равных 0, ввод чисел с плавающей точкой, ввод любых символов, кроме целых чисел. Программа будет требовать ввода допустимого значения и не продолжит выполнения, до тех пор, пока пользователь не введет допустимое значение.
3. Блок обработки матрицы и вывода. Создает матрицу заданной размерности и заполняет ее вводимыми пользователем числами, после чего транспонирует ее. Ввод значений матрицы проверяется на правильность, если значение не является допустимым, программа будет требовать ввести число заново, до тех пор, пока значение не станет корректным. Затем происходит вывод полученного результата на экран консоли с помощью перемены местами индексов i и j во вложенном цикле.

#Потоки данных
1. Ввод пользователем корректных значений размерности матрицы
2. Ввод пользователем корректных значений элементов матрицы, создание матрицы заданной размерности с введенными числами
3. Вывод матрицы в транспонированном виде
