#Тестирование ввода размеров матрицы
1. Ввод положительных целых чисел (позитивный): Ожидается продолжение работы программы.
2. Ввод чисел <= 0 (граничный): Ожидается запрос повторного ввода.
3. Ввод чисел с плавающей точкой (округление): Ожидается округление ввода и продолжение работы программы.
4. Ввод текста или иных символов (негативный): Ожидается запрос повторного ввода.

#Тестирование ввода элементов матрицы
1. Ввод вещественных чисел (позитивный): Ожидается продолжение работы программы.
2. Ввод текста и иных символов (негативный): запрос повторного ввода.
